# Интерактивный пульт VINTEO

Автономная демонстрация модели пульта и отклика условного терминала. Откройте `index.html` в современном браузере — установка и подключение к интернету не нужны. Пульт реагирует на нажатия мыши; также предусмотрено управление с клавиатуры: стрелки, Enter, Escape, M и цифровые клавиши после выбора элемента внутри страницы.

**Это прототип:** терминал справа и его действия демонстрационные, соединения с устройством нет. Для управления реальным терминалом потребуется отдельная интеграция.

## Передача команды в приложение

В исходном HTML событие `remote-command` возникает на элементе `#remote-study` при действии пульта и содержит название команды в `event.detail.command`. Значение `source: 'demo'` и другие данные события относятся к демонстрации. Приложение может подписаться на событие и самостоятельно сопоставить команды со своим API. Интерфейс, протокол и подключение терминала в проект не входят.

Настройки демонстрации могут сохраняться локально в браузере. Иконки Lucide встроены в HTML; условия их использования приведены в `LICENSE-lucide.txt`.
